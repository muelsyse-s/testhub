# 接口说明

所有接口以 `/api` 为前缀，统一返回：

```json
{ "code": 0, "msg": "ok", "data": {} }
```

`code` 为 0 表示成功；401 未登录、403 无权限、400 参数或业务校验失败、404 资源不存在、500 服务端异常。
除登录接口外，均需在请求头携带 `Authorization: Bearer <token>`。

## 认证

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/auth/login | 账号密码登录，返回 token 与角色 |
| GET | /api/auth/me | 当前登录用户信息 |
| POST | /api/auth/logout | 退出（前端清除 token） |

```http
POST /api/auth/login
Content-Type: application/json

{ "username": "wtb", "password": "123456" }
```

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "token": "eyJhbGciOiJIUzUxMiJ9...",
    "id": 1,
    "username": "wtb",
    "realName": "王童博",
    "roles": ["ADMIN"]
  }
}
```

## 接口自动化

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST/PUT/DELETE | /api/apis | 接口定义 |
| GET/POST/PUT/DELETE | /api/api-scripts | 脚本管理 |
| POST | /api/api-scripts/{id}/run?envId= | 执行单个脚本 |
| POST | /api/api-scripts/run-batch | 批量执行 |
| GET | /api/api-run-logs | 执行日志分页 |
| GET | /api/api-scripts/variables | 全局变量池 |
| GET/POST/PUT/DELETE | /api/environments | 环境管理 |

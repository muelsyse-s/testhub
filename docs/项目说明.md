# 项目说明

本目录包含《综合实践训练》的公开文档与配图。

## 交付物

| 文件 | 说明 |
|---|---|

> 课程报告与学习笔记（docx 与 pdf）因包含个人姓名、学号等信息，**未放入本公开仓库**，需要时请向作者索取。两份文档的结构如下。

## 报告结构

1. **第 1 章 绪论**：项目背景、研究意义、国内外研究与应用现状（含现状问题调研表）、主要研究内容、论文组织结构；
2. **第 2 章 系统分析**：2.1 可行性分析（技术/经济/操作/法律）、2.2 需求分析（角色、功能需求、用例图与用例描述、业务流程、非功能需求）；
3. **第 3 章 系统设计**：3.1 概要设计（总体架构、部署拓扑、技术选型、功能结构）、3.2 模块设计（用例管理、测试执行、接口脚本、缺陷跟踪，含活动图与时序图）、3.3 数据库设计（E-R 图与 5 张核心表）、3.4 安全设计；
4. **第 4 章 系统实现**：4.1 系统页面设计（11 张界面截图）、4.2 技术实现（环境、后端、前端、脚本引擎）、4.3 系统测试（功能测试、接口自动化测试、缺陷统计）；
5. **结论与参考文献**。

# 项目说明

本目录包含《综合实践训练》的公开文档与配图。

## 报告结构

1. **第 1 章 需求分析**：项目背景、现状问题调研、12 个功能模块、非功能需求；
2. **第 2 章 系统分析**：四维可行性、四类角色、用例图与用例描述、业务流程；
3. **第 3 章 系统设计**：三层架构与部署拓扑、技术选型、功能结构、14 张表的数据库设计、时序图与活动图、安全设计；
4. **第 4 章 系统实现与测试**：环境、11 张界面截图、功能测试与接口自动化测试结果、缺陷统计；
5. **结论与参考文献**。

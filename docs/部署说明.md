# 部署说明

## 环境要求

| 组件 | 版本 |
|---|---|
| JDK | 21+ |
| Maven | 3.9+ |
| Node.js | 20+ |
| MySQL | 8.0（生产）或使用内置 H2 演示 |

## 本地运行

### H2 演示模式（默认）

```bash
cd backend
mvn spring-boot:run
```

启动时自动执行 `db/h2/schema.sql` 与 `db/h2/data.sql`，控制台可通过 <http://127.0.0.1:8080/h2-console>
（JDBC URL：`jdbc:h2:mem:testhub`，用户名 `sa`，空密码）查看数据。

### MySQL 模式

```bash
mysql -uroot -p < db/schema-mysql.sql
mysql -uroot -p < db/data-mysql.sql
java -jar backend/target/testhub.jar --spring.profiles.active=mysql
```

支持的环境变量：

| 变量 | 默认值 | 说明 |
|---|---|---|
| MYSQL_HOST | localhost | 数据库地址 |
| MYSQL_PORT | 3306 | 端口 |
| MYSQL_DB | testhub | 库名 |
| MYSQL_USER | root | 用户名 |
| MYSQL_PASSWORD | root | 密码 |

### 前端

```bash
cd frontend
npm install
npm run dev      # 开发：http://127.0.0.1:5173，/api 代理到 8080
npm run build    # 生产：产物在 dist/
```

## Docker Compose 一键部署

```bash
cd deploy
docker compose up -d --build
```

启动顺序：MySQL（健康检查通过）→ 后端 → 前端 Nginx。访问 <http://localhost>。

常用命令：

```bash
docker compose logs -f backend     # 查看后端日志
docker compose down                # 停止
docker compose down -v             # 停止并清空数据卷
```

## 生产方式运行

1. 前端 `npm run build`，将 `dist/` 交给 Nginx；
2. Nginx 参考 `deploy/nginx.conf`：静态资源 + `try_files` 回落 + `/api` 反向代理；
3. 后端以 `java -jar testhub.jar --spring.profiles.active=mysql` 运行，建议配合 systemd 或容器编排；
4. 生产环境务必修改 `testhub.jwt.secret`，并通过环境变量或配置中心注入数据库密码。
